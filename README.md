# Karan Singh Transport Services

Professional B2B transportation & logistics website for pan-India freight services.

![Karan Singh Transport Services](https://customer-assets.emergentagent.com/job_karan-freight/artifacts/7n62afik_logo.PNG)

## 🚀 Static Website - No Backend Required!

This is a **pure static React website** that can be hosted anywhere for free.

## Features

- **6 Pages:** Home, About Us, Services, Service Routes, Associate Network, Contact
- **Contact Form:** Sends emails via Formspree (no server needed)
- **Responsive Design:** Mobile-friendly Swiss Industrial theme
- **Fast Loading:** Static files served via CDN

## Tech Stack

- **Frontend:** React 19, Tailwind CSS, Shadcn UI
- **Form Handling:** Formspree (free email service)
- **Hosting:** Any static host (Netlify, Vercel, Namecheap, GitHub Pages)

## Quick Start

```bash
cd frontend
yarn install
yarn start
```

## Build & Deploy

```bash
cd frontend
yarn build
# Upload 'build' folder to your hosting
```
