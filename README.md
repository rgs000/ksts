# Karan Singh Transport Services

Professional B2B transportation & logistics website for pan-India freight services.

![Karan Singh Transport Services](https://customer-assets.emergentagent.com/job_karan-freight/artifacts/7n62afik_logo.PNG)

## Features

- **6 Pages:** Home, About Us, Services, Service Routes, Associate Network, Contact
- **Contact Form:** With email notifications via SMTP
- **Responsive Design:** Mobile-friendly Swiss Industrial theme
- **Fleet Info:** 10 own trucks + 50 associate trucks
- **Route Coverage:** Ghaziabad NCR → Agra → Nagpur → Hyderabad → Bengaluru → Chennai

## Tech Stack

- **Frontend:** React 19, Tailwind CSS, Shadcn UI
- **Backend:** FastAPI (Python)
- **Database:** MongoDB
- **Email:** SMTP (Namecheap Private Email)

## Quick Start

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn server:app --reload --port 8001
```

### Frontend
```bash
cd frontend
yarn install
yarn start
```
